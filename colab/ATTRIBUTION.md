# Demo image attribution

The prepared images in `colab/demo_samples/` are derivative validation examples
used only to demonstrate the inference interface. They are not presented as a
new evaluation set or as independent evidence of model performance.

## Sources

- **Damaged Box Detection**, provided by a Roboflow Universe user under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/):
  <https://universe.roboflow.com/project-33xgh/damaged-box-detection>
- **My First Project / damaged-package-detection**, provided by a Roboflow
  Universe user under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/):
  <https://universe.roboflow.com/damaged-package-detection/my-first-project-5g94h>

The filenames were shortened for the presentation bundle. No model prediction is
used as ground truth; labels come from the project's reviewed validation data.
